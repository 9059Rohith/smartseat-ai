The correction carries actual person boxes with the captured scan frame, excludes people from common view evidence, checks available background outside all proposals once, and validates each visible table region independently. Close-ups without sufficient separate background retain the conservative global check. Changed or heavily occluded table regions are rejected. The actual current camera image is always used for display; archived images are never substituted into the feed.
